# Contributing to Pocket Tavern

Thanks for wanting to help! Pocket Tavern is in alpha, so bug reports, ideas and pull requests are all welcome.

## Bugs and ideas

Use the [issue forms](https://github.com/brabro1/SillyTavern-PocketTavern/issues/new/choose). A screenshot, your layout (Phone or Desktop), device and browser, theme, other extensions, and SillyTavern version help the most. Please never share private chats, API keys or other personal data.

## Code

- **[`AGENTS.md`](AGENTS.md):** how we work, the rules that protect SillyTavern and your data, and what "done" means. It is written for people and AI coding tools alike.
- **[`DESIGN.md`](DESIGN.md):** read it before any change to the interface.
- **[`docs/development.md`](docs/development.md):** setting up a test SillyTavern, running the checks and tests, and where things go.

Before opening a pull request:
1. Say whether it is for **Phone**, **Desktop** or **Both**.
2. Run `cd tests && npm run check`.
3. Run the tests for what you changed against a **test** SillyTavern.
4. Look at screenshots on both layouts.
5. Translate every new label into all six languages.

Keep changes small and focused, and write text people see in plain, friendly words.
